МГУУ WEB v0.30 С СДО
ПОШАГОВАЯ ПУБЛИКАЦИЯ И УСТАНОВКА ТОЛЬКО С IPHONE

ПОДГОТОВКА
1. Скачайте ZIP-архив в приложение «Файлы».
2. Откройте папку «Загрузки» и один раз нажмите на ZIP.
3. Рядом появится распакованная папка.
4. Внутри должны лежать index.html, app.js, server.js, package.json, render.yaml и остальные файлы. Все они должны быть на одном уровне.

ЧАСТЬ 1. ЗАГРУЗИТЬ ФАЙЛЫ В GITHUB
1. Откройте github.com в Safari и войдите в свою учётную запись.
2. Создайте новый репозиторий, например mguu-web. Лучше выбрать Private.
3. Откройте репозиторий и нажмите Add file → Upload files.
4. В приложении «Файлы» откройте распакованную папку и выберите ВСЕ файлы внутри неё.
5. После загрузки нажмите Commit changes.
6. На главной странице репозитория должны быть сразу видны:
   index.html
   app.js
   server.js
   package.json
   render.yaml
   sw.js
   manifest.webmanifest
   Они не должны находиться внутри дополнительной папки.

ЧАСТЬ 2. НОВОЕ РАЗВЁРТЫВАНИЕ НА RENDER — РЕКОМЕНДУЕТСЯ
Этот способ автоматически создаёт секретный ключ для безопасной сессии СДО.

1. Откройте dashboard.render.com в Safari и войдите через GitHub.
2. Разрешите Render доступ к репозиторию mguu-web.
3. Нажмите New → Blueprint.
4. Выберите репозиторий mguu-web.
5. Render найдёт файл render.yaml.
6. Подтвердите создание сервиса кнопкой Apply или Deploy Blueprint.
7. Дождитесь статуса Live.
8. Откройте адрес вида https://mguu-web-xxxx.onrender.com.

Файл render.yaml сам задаёт:
- Node;
- npm install;
- npm start;
- /api/health;
- MGUU_SESSION_SECRET со случайным защищённым значением.

ЧАСТЬ 2Б. ЕСЛИ ВЕРСИЯ v0.28 УЖЕ РАБОТАЕТ НА RENDER
1. Замените файлы в прежнем репозитории GitHub файлами из v0.30 и сделайте Commit changes.
2. Render обычно начнёт Auto-Deploy самостоятельно.
3. В Render откройте свой Web Service → Environment.
4. Добавьте переменную:
   Key: MGUU_SESSION_SECRET
   Value: длинная уникальная случайная строка не короче 32 символов.
5. Нажмите Save and deploy.

Без этой переменной СДО тоже запустится, но после перезапуска бесплатного сервера вход может сброситься и потребуется войти снова.

ЧАСТЬ 3. УСТАНОВИТЬ НА ЭКРАН IPHONE
1. Откройте адрес Render именно в Safari.
2. Дождитесь полной загрузки расписания.
3. Нажмите «Поделиться» — квадрат со стрелкой вверх.
4. Выберите «На экран Домой».
5. Включите «Открывать как веб-приложение».
6. Проверьте название «МГУУ».
7. Нажмите «Добавить».
8. Закройте Safari и запускайте приложение с нового ярлыка.

ЧАСТЬ 4. ВОЙТИ В СДО
1. Запустите МГУУ с ярлыка на экране Домой.
2. Проведите пальцем вправо от левого края или откройте боковое меню.
3. Нажмите «СДО».
4. Введите свой обычный логин и пароль от online.mguu.ru.
5. Нажмите «Войти».
6. После успешного входа появятся:
   - ближайшие задания и события;
   - мои курсы;
   - оценки, доступные через Moodle API.
7. Нажатие на курс открывает его материалы и оценки.
8. Тесты и сложные задания открываются на официальном сайте СДО.

Пароль не сохраняется. В браузерном хранилище токена тоже нет: сервер держит его в зашифрованной HttpOnly-сессии.

ЕСЛИ ВХОД НЕ РАБОТАЕТ
1. Проверьте логин и пароль на официальном сайте online.mguu.ru.
2. Нажмите «Открыть официальный сайт СДО» в приложении.
3. Если обычный сайт принимает данные, а приложение пишет, что мобильный доступ отключён, значит администрация Moodle не разрешила мобильный веб-сервис. Это нельзя исправить на стороне приложения без участия МГУУ.
4. Логин и пароль никому не отправляйте.

ОБНОВЛЕНИЕ УСТАНОВЛЕННОГО ЯРЛЫКА
После замены файлов на GitHub и завершения Deploy в Render новый код загрузится автоматически. Иногда iPhone сохраняет старый service worker. Тогда:
1. полностью закройте МГУУ;
2. откройте адрес Render в Safari и обновите страницу;
3. снова запустите ярлык;
4. если версия внизу всё ещё старая, удалите ярлык и добавьте его на экран Домой заново. Локальные личные дела при удалении данных сайта могут потеряться.
