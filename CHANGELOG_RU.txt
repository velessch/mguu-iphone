МГУУ Web v0.30 — iPhone / GitHub

Основа: Web v0.29.

Изменения:
- подготовлена структура репозитория для прямой загрузки в GitHub;
- добавлен README.md для страницы репозитория и 00_GITHUB_START_RU.txt;
- добавлен .gitignore для .env, node_modules и служебных файлов;
- версия приложения, сервера и service worker обновлена до v0.30;
- cache service worker обновлён, чтобы iPhone не оставался на старой v0.29;
- усилена адаптация Safari/PWA под safe-area: верхняя область, Dynamic Island/чёлка, боковые inset и Home Indicator;
- добавлены iPhone-мета-теги и защита от изменения размера текста Safari;
- сохранена защищённая схема входа в СДО через HttpOnly-cookie и Render secret;
- инструкция публикации уточнена: GitHub хранит проект, Render запускает Node.js-сервер.

Не изменялось:
- пароль СДО не хранится;
- фоновые push-уведомления при полностью закрытом приложении не добавлены;
- реальные учётные данные СДО не использовались при тестировании.
