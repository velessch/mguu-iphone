МГУУ Web v0.31 — iPhone / Safari / PWA

Исправления:
- Исправлен бесконечный экран загрузки при публикации в GitHub Pages.
- Все PWA-ресурсы переведены с абсолютных /... путей на относительные ./... пути.
- Эмблема на самом первом экране встроена прямо в index.html и не зависит от пути к файлу.
- Исправлены manifest start_url/scope/id для репозитория GitHub Pages.
- Исправлен service worker для работы из подпапки репозитория.
- Исправлены пути иконок уведомлений и экрана входа в СДО.
- Добавлен понятный экран ошибки, если приложение открыто прямо с GitHub Pages без Node.js backend.

Важно:
GitHub хранит исходники. Для полного расписания, рейтинга и СДО репозиторий нужно развернуть как Web Service на Render, потому что GitHub Pages не запускает server.js.
