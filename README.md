# МГУУ Web v0.30 — iPhone

Веб/PWA-версия приложения «МГУУ» для iPhone и Safari.

## Возможности

- расписание: день / неделя / календарь;
- выбор группы;
- рейтинг и личные дела;
- светлая и тёмная темы;
- установка на экран «Домой»;
- интерфейс с учётом iPhone safe-area;
- раздел СДО через защищённый Node.js-прокси.

## Как опубликовать

Загрузите **все файлы этого проекта в корень GitHub-репозитория**, затем подключите репозиторий в **Render → New → Blueprint**. Конфигурация находится в `render.yaml`.

> GitHub Pages сам по себе не запускает `server.js`. Для полной версии с СДО нужен Render или другой Node.js-хостинг.

После развёртывания откройте HTTPS-адрес Render в Safari на iPhone: **Поделиться → На экран Домой → Открывать как веб-приложение**.

Подробно: `INSTALL_IPHONE_RU.txt`. Безопасность СДО: `SECURITY_SDO_RU.txt`.
