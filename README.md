# МГУУ Web v0.31 — iPhone

PWA-версия приложения МГУУ для Safari/iPhone.

## Исправлено в v0.31

- запуск из подпапки GitHub Pages;
- эмблема на стартовом экране;
- относительные пути PWA-ресурсов;
- `start_url`, `scope` и service worker;
- защита от бесконечной заставки при ошибке загрузки JS.

## Публикация

GitHub используется как репозиторий исходников. Для полной работы расписания, рейтинга и СДО разверните этот репозиторий в Render (конфигурация `render.yaml` уже включена), затем устанавливайте на iPhone URL Render через Safari → Поделиться → На экран Домой.
