МГУУ Web v0.43 — проверка перед выдачей

Цель: iPhone / Safari / PWA / Vercel.
База: iPhone Web v0.42; Android universal v0.54 использован как функциональный эталон рейтинга.

Проверено:
- синтаксис app.js, api/backend.mjs и sw.js;
- 10 автоматических регрессионных тестов;
- маршрутизация portal.mguu.ru -> Vercel proxy без подмены канонических URL;
- network-only/no-store для /portal/* и /api/*;
- PWA cache/build 043;
- исправление ошибочного дублирующего ID нового учебного года;
- отсутствие жестко заданного year=000000033 в app.js;
- реальные колонки «Модуль 1 / Модуль 2 / Общий балл» не сдвигаются;
- текущий «Модуль 1» виден на закрытой карточке, если общий балл еще пуст;
- новая карточка дисциплины добавляется даже до появления баллов;
- уведомление создается для первой оценки в новой карточке;
- уведомление создается для новой оценки в существующей карточке;
- нет ложного повторного уведомления при раскрытии известного «Модуля 1» в КТ;
- нет дубля уведомления при одновременном изменении КТ и общего итога;
- iPhone-интерфейс и настройки исходной Web/PWA-ветки сохранены.

Живой формат портала также перепроверен: 2026/2027 сейчас содержит конфликтующий value в option,
а рабочие personalrating.php/detailed.php используют фактический ID; v0.43 определяет его динамически.
