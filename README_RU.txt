МГУУ Web v0.30 — iPhone / Safari / PWA

Это готовая версия проекта для публикации в GitHub и последующего развёртывания на Render.
GitHub хранит исходники проекта, а Render запускает Node.js-сервер, необходимый для прокси расписания/рейтинга и безопасного входа в СДО.

Что есть в версии
------------------
- расписание МГУУ с режимами День / Неделя / Календарь;
- выбор группы;
- рейтинг;
- личные дела;
- светлая и тёмная темы;
- установка на экран Домой как веб-приложение;
- safe-area для iPhone с Dynamic Island/чёлкой и нижним Home Indicator;
- СДО: вход, курсы, ближайшие задания, оценки и материалы, доступные мобильному Moodle API;
- уведомления при открытии/обновлении приложения;
- офлайн-кэш оболочки PWA.

Безопасность СДО
----------------
Пароль не сохраняется. Сервер использует его только для запроса Moodle-токена. Токен шифруется AES-256-GCM и хранится в HttpOnly-cookie; JavaScript приложения его не видит. Секрет MGUU_SESSION_SECRET создаётся Render автоматически через render.yaml.

Публикация
----------
1. Распакуйте ZIP.
2. Создайте GitHub-репозиторий и загрузите ВСЕ файлы из этой папки в корень репозитория.
3. В Render выберите New → Blueprint и подключите этот репозиторий.
4. Render найдёт render.yaml и создаст веб-сервис.
5. Откройте полученный HTTPS-адрес в Safari на iPhone.
6. Поделиться → На экран Домой → Открывать как веб-приложение.

Важно: обычный GitHub Pages не запускает server.js. Без Node.js-сервера СДО и серверные прокси не будут работать. Для полной версии используйте Render (или другой Node.js-хостинг).

Основные файлы
---------------
index.html — стартовая страница;
app.js — интерфейс;
server.js — Node.js-сервер и безопасный Moodle-клиент;
render.yaml — конфигурация Render;
sw.js — service worker;
manifest.webmanifest — параметры PWA;
package.json — запуск Node.js;
SECURITY_SDO_RU.txt — сведения о безопасности;
INSTALL_IPHONE_RU.txt — пошаговая инструкция.
