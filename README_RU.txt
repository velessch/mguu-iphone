# МГУУ Web v0.43 — iPhone / Vercel

Веб/PWA-версия МГУУ для iPhone. Интерфейс и настройки iPhone сохранены, а логика рейтинга синхронизирована с единой Android v0.54 как с функциональным эталоном.

## Что изменено в v0.43

- исправляется ошибочный/дублирующий ID нового учебного года по фактическим ссылкам `personalrating.php` и `detailed.php`, без жёстко заданного ID;
- новые дисциплины добавляются карточками даже до появления баллов;
- `Модуль 1`, `Модуль 2` и `Общий балл` читаются по своим реальным колонкам и не сдвигаются при пустых значениях;
- если общий балл ещё пуст, на закрытой карточке показывается доступный `Модуль 1`;
- новая оценка определяется как в существующей, так и в новой карточке;
- раскрытие уже известного `Модуля 1` в детальные КТ не создаёт ложное повторное уведомление;
- при одновременном изменении КТ и общего итога уведомление не дублируется;
- сохранены канонические URL портала, Vercel-прокси и PWA/network-only правила предыдущей ветки.

## Публикация

1. Загрузите содержимое проекта в GitHub.
2. Импортируйте репозиторий в Vercel как **Other**.
3. Добавьте `MGUU_SESSION_SECRET` в **Settings → Environment Variables** и выполните Redeploy.
4. Откройте `/api/health`: `version` должен быть `0.43`, а `sessionSecretConfigured` — `true`.
5. Используйте URL Vercel как основной адрес приложения на iPhone.

Подробнее: `00_VERCEL_START_RU.txt`.

## Безопасность СДО

Пароль не сохраняется. Moodle-токен шифруется AES-256-GCM и хранится в HttpOnly cookie. Ключ шифрования задаётся только через переменную окружения Vercel и не должен попадать в GitHub.
