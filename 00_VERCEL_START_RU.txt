МГУУ Web v0.41 — iPhone / Vercel

ЭТОТ АРХИВ ПОДГОТОВЛЕН ДЛЯ VERCEL.

1. Распакуйте ZIP.
2. В GitHub удалите/замените старые файлы проекта файлами из этого архива.
3. В корне репозитория должны быть index.html, app.js, vercel.json, package.json и папка api.
4. Откройте Vercel → Add New → Project → Import Git Repository.
5. Выберите ваш репозиторий МГУУ.
6. Framework Preset: Other. Остальные Build Settings оставьте по умолчанию.
7. Нажмите Deploy.
8. После первого Deploy откройте Project → Settings → Environment Variables.
9. Создайте переменную MGUU_SESSION_SECRET со случайной длинной строкой (не публикуйте её в GitHub). Отметьте Production и Preview.
10. Сделайте Redeploy.
11. Проверьте адрес https://ВАШ-ПРОЕКТ.vercel.app/api/health — должен вернуться JSON с version 0.38 и sessionSecretConfigured true.
12. Откройте основной адрес Vercel на iPhone в Safari.
13. Safari → Поделиться → На экран Домой → Открывать как веб-приложение.

Важно: пароль СДО не сохраняется. Он используется серверной функцией только для получения Moodle-токена.

Примечание v0.41: в vercel.json нет ручного блока functions; Vercel автоматически обнаруживает api/backend.mjs.
