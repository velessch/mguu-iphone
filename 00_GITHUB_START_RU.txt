МГУУ Web v0.31 — публикация для iPhone

1. Распакуйте ZIP.
2. Загрузите ВСЕ файлы из папки в корень GitHub-репозитория. Сам ZIP в репозиторий загружать не нужно.
3. После загрузки в GitHub подключите репозиторий к Render как Web Service. В проект уже включён render.yaml.
4. Используйте именно адрес Render как адрес приложения на iPhone.
5. На iPhone откройте адрес Render в Safari → Поделиться → На экран Домой → Открывать как веб-приложение.

GitHub Pages теперь тоже корректно показывает интерфейс и эмблему, но НЕ может запускать server.js. Поэтому расписание/рейтинг/СДО в полном режиме должны открываться по адресу Render.
