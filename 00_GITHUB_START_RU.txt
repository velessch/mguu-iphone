МГУУ Web v0.30 — ЧТО ЗАГРУЖАТЬ В GITHUB

1. Распакуйте этот ZIP.
2. Создайте репозиторий GitHub.
3. Загрузите ВСЕ файлы из распакованной папки в КОРЕНЬ репозитория.
4. Не создавайте .env и не добавляйте пароли/токены/секреты в GitHub.
5. Для полной работы подключите репозиторий в Render через New → Blueprint.
6. Откройте выданный Render HTTPS-адрес в Safari на iPhone и добавьте на экран Домой.

СДО не требует хранения пароля в репозитории. MGUU_SESSION_SECRET создаётся Render автоматически.
